One line, 109 characters: an agent apologises for shipping a bug — it did review the code first, but it asked itself, and it has never disagreed with itself. The program in `main.ts` writes that single line to `entry.txt` in the output directory, after checking it against the 200-character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
